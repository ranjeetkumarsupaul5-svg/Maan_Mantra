# Maan Mantra

Maan Mantra is a machine learning based web application that predicts a student's mental health score using information related to study, sleep, physical activity, stress, and social media usage.

The project combines a trained Scikit-learn model with a FastAPI backend and a simple HTML, CSS, and JavaScript frontend.

## Features

- Student mental health score prediction
- Machine learning based prediction
- FastAPI REST API
- Pydantic input validation
- Scikit-learn preprocessing pipeline
- Interactive web interface
- Frontend and backend integration
- Swagger API documentation
- Render deployment

## Input Features

The model uses:

- Age
- Gender
- Country
- Academic Level
- Most Used Platform
- Purpose of Use
- Average Daily Usage Hours
- Daily Unlocks
- Study Hours
- Physical Activity Hours
- Sleep Hours Per Night
- Stress Level

## Machine Learning

The project uses a Scikit-learn preprocessing pipeline before making predictions.

The preprocessing includes:

- Log transformation for skewed numerical features
- StandardScaler for numerical features
- OrdinalEncoder for Stress Level
- OneHotEncoder for categorical features
- Grouping less frequent countries into an "Other" category

The final model used for prediction is Linear Regression.

The complete trained pipeline is saved using Joblib as:

Mental_Health_Score.pkl

## Run Locally

Clone the repository:

git clone https://github.com/ranjeetkumarsupaul5-svg/Maan_Mantra.git

Open the project directory:

cd Maan_Mantra

Install dependencies:

pip install -r requirements.txt

Start the FastAPI server:

python -m uvicorn main:app --port 2200 --reload

Open the application:

http://127.0.0.1:2200

## API Documentation

FastAPI Swagger documentation:

## API Endpoint

POST /predict

The endpoint accepts student information and returns the predicted mental health score.

Example response:

{
  "predicted_mental_health_score": 72.45
}
